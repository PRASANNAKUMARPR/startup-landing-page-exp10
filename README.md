
# Startup Landing Page - Experiment 10

## Title
HTML Form Request Handling Using Node.js and MongoDB

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- MongoDB

## Features
- User Registration Form
- Node.js HTTP Server
- POST Request Handling
- MongoDB Database Connection
- Store Registration Details
- Display Submitted Details

## How to Execute

1. Install Node.js.
2. Install MongoDB and start the database server.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run npm install.
6. Configure the MongoDB connection in .env.
7. Run npm start.
8. Open http://localhost:2000 in your browser.

## Result
Successfully developed a registration form using Node.js
and MongoDB to handle and store user details.
